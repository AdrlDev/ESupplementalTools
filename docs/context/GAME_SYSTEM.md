# Game system

The game catalogue is `data/model/game/GameCatalogue.kt`; IDs are in `domain/model/game/GameId.kt`. All active games are dispatched from `navigation/NavGraph.kt` through `Screen.GamePlayer`.

| Name | Entry screen / ViewModel | Content source | Core logic | Score / completion |
|---|---|---|---|---|
| Word Master (`listen_slap`) | `easy/word_master/WordMasterScreen.kt` / `WordMasterViewModel` | `WordMasterBank`: unique 4–12 letter words extracted from all story assets | Hear generated word audio, type exact word, 15-second timer after audio, case-insensitive answer | 10 rounds; +1 exact answer; XP is `score / 10 * 10`; saves game aggregate at game over |
| Story Order (`story_order`) | `easy/story_order/StoryOrderScreen.kt` / `StoryOrderViewModel` | Room `story_activities`, generated by `StoryActivityFactory` | Hear a five-event summary, drag shuffled events into order, check each position | Up to 5 stories; one point per correctly positioned event; XP 15 for an all-correct story, otherwise 3 per correct event; saves against total event positions |
| Character Quest (`character_quest`) | `easy/character_quest/CharacterQuestScreen.kt` / `CharacterQuestViewModel` | `CharacterQuestBank`: nine static character profiles with quotes selected from story Markdown | Hear quote/trait, choose one of four characters; feedback delay | Five shuffled questions; +1 correct; XP 15 correct/3 wrong; saves at game over |
| Disappearing Text (`disappearing_text`) | `moderate/disappearing_text/DisappearingTextScreen.kt` / `DisappearingTextViewModel` | `DisappearingTextBank`: one deterministic sentence per story asset | Hear sentence, 5-second read timer, remove one word every 400 ms, type normalized sentence exactly | Up to five rounds; +1 exact normalized answer; XP is `score / total * 15`; saves at game over |
| 2 Truths 1 Lie (`two_truths_lie`) | `moderate/two_truths_lie/TwoTruthsLieScreen.kt` / `TwoTruthsLieViewModel` | `TwoTruthsLieBank`: two source sentences plus a sentence from another story | Hear only the two truths, then select the shuffled statement not spoken | Five rounds; +1 when selected statement is the lie; XP is `score / total * 15`; saves at game over |
| Minimal Pairs Battle (`minimal_pairs`) | `moderate/minimal_pairs/MinimalPairsScreen.kt` / `MinimalPairsViewModel` | Curated word pairs filtered to words occurring in story assets | Hear one randomly chosen word from a pair, choose the heard word | Eight rounds when enough pairs exist; non-repeating words preferred; +1 correct; XP is `score / total * 15`; saves at game over |
| Speed Typer (`speed_typer`) | `hard/speed_typer/SpeedTyperScreen.kt` / `SpeedTyperViewModel` | `SpeedTyperBank`: first five suitable 4–8 word sentences per story | Hear excerpt, type exact normalized text within 15 seconds | Four rounds; +1 exact answer; XP is `score / 4 * 35`, minimum 5; saves at game over |
| Follow the Directions (`follow_directions`) | `hard/follow_directions/FollowDirectionsScreen.kt` / `FollowDirectionsViewModel` | `FollowDirectionsBank`: four deterministic challenges per story | Hear instruction, move a character on a 5×5 grid; one extra move is allowed | Four rounds; +1 on reaching target before moves expire; XP is `score / 4 * 35`, minimum 5; saves at game over |
| Story Recall Challenge (`story_recall`) | `hard/story_recall/StoryRecallScreen.kt` / `StoryRecallViewModel` | `StoryRecallBank`: five questions generated from selected story sentences and moral | Hear question, choose one of four answers; selection submits immediately | Up to five rounds; +1 correct; XP is `score / total * 40`, minimum 10; saves at game over |

## Shared game mechanics

- Each game has a feature-specific `UiState` and phase enum; most render start, gameplay, feedback, and result through `GameResultScreen`.
- Game progress locking is computed in `GameScreenViewModel`: Easy is open; Moderate requires all Easy games completed; Hard requires all Moderate games completed. Within a tier, the previous catalogue item must have stars.
- `BuildConfig.ALLOW_GAME_PROGRESSION_BYPASS` disables progression locking in staging/demo.
- `GameScoring` maps percentage to 0–3 stars: 100% → 3, 70–99% → 2, 40–69% → 1, below 40% → 0.
- Game results are not recorded as individual history rows. Only the per-user `games` row is updated with max stars and max XP.
- Optional `mediaId` is accepted by game routes/ViewModels, but the main Game screen currently navigates with game ID only; story selection is random or bank-specific.
